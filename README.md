# Mobexler – TP Virtualisation

## Description
Ce projet consiste à déployer la machine virtuelle Mobexler avec VirtualBox
et à configurer le réseau pour l’analyse de sécurité mobile.

## Environnement
- OS : Windows
- VirtualBox
- Mobexler.ova

## Étapes réalisées
- Importation de Mobexler.ova
- Configuration réseau (NAT + Host-Only)
- Démarrage de la machine
- Connexion ADB
- Création d’un snapshot CLEAN
- Vérification SHA256
